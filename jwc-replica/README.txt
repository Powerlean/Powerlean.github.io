也支持 /User/Default.aspx 路径。仅需 Node.js，无须安装依赖。
检查：npm run check。

范围：还原已分享的登录后首页，保留原页 1000px 固定宽度布局、样式、横幅、菜单与服务入口。

业务入口在新标签页打开原站，需要原站登录与相应网络访问权限。
退出按钮仅退出本地预览，不注销原站会话。收藏和主页操作提供现代浏览器操作提示。
未复制 ASP.NET 会话隐藏字段。个人照片使用用户提供的附件，在本地抠图、替换为白底并裁为 3:4 证件照比例，保存为 assets/portrait-white.png；原附件未修改。
页面包含已分享页面的姓名和学号，仅供本地使用。
页面依赖的可用图片、样式和图标字体保存在 assets 中；原站已失效的装饰资源未恢复。
